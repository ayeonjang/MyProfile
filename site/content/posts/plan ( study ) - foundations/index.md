# 컴퓨터 과학 및 수학 기초

## 학습 개요

Physical AI와 로보틱스를 공부하기 위해서는 컴퓨터 과학, 프로그래밍, 수학에 대한 탄탄한 기초를 먼저 갖추는 것이 중요하다고 생각한다.

Physical AI는 인공지능을 실제 물리적 시스템과 결합하는 분야이다. 이러한 시스템을 이해하고 개발하기 위해서는 알고리즘이 작동하는 원리뿐만 아니라 알고리즘이 실제 환경과 어떻게 상호작용하는지도 이해해야 한다.

## 학습 목표

### 1. 프로그래밍 역량 강화

- Python 프로그래밍 능력을 향상한다.
- 시스템 및 로봇 프로그래밍에 활용되는 C와 C++를 학습한다.
- 효율적이고 유지보수하기 쉬운 코드를 작성하는 연습을 한다.

### 2. 컴퓨터 과학 기초 학습

- 자료구조와 알고리즘의 기본 개념을 학습한다.
- 문제 해결 기법과 시간 및 공간 복잡도를 이해한다.
- 주어진 문제를 분석하고 적절한 알고리즘을 설계하는 능력을 기른다.

### 3. 수학적 기초 학습

- 벡터와 행렬을 중심으로 선형대수를 학습한다.
- 미적분학의 기본 개념을 이해한다.
- 인공지능 분야에 활용되는 확률과 통계의 기초를 학습한다.

## 학습 방법

전공 수업과 프로그래밍 실습, 개인 프로젝트를 통해 기초 역량을 단계적으로 쌓아 나갈 계획이다.

이론적인 개념을 익히는 데 그치지 않고, 직접 코드를 작성하고 실행 결과를 확인하면서 학습한 내용을 실제로 적용해 보고자 한다.

특히 Constraint Satisfaction Problem(CSP)을 활용한 Nonogram 퍼즐 해결 프로젝트를 수행하면서 알고리즘 설계와 성능 분석의 중요성을 경험했다. 이러한 경험을 바탕으로 앞으로도 문제를 분석하고 적절한 알고리즘을 선택하여 구현하는 능력을 발전시키고자 한다.

## 기대하는 학습 결과

이번 단계에서는 프로그래밍 능력과 컴퓨터 과학적 사고력, 수학적 이해를 갖추는 것을 목표로 한다.

이를 바탕으로 이후 머신러닝과 딥러닝, 컴퓨터 비전, 로보틱스 분야를 학습하기 위한 기초를 마련하고자 한다.

# 인공지능 및 컴퓨터 비전

## 학습 개요

컴퓨터 과학과 수학의 기초를 다진 다음에는 인공지능과 컴퓨터 비전 분야를 학습하고자 한다.

Physical AI가 실제 환경을 이해하고 상황에 맞게 행동하기 위해서는 주변 환경에서 얻은 데이터를 분석하고 의미 있는 정보를 추출하는 능력이 필요하다. 특히 카메라와 같은 시각 센서를 통해 주변 환경을 인식하는 컴퓨터 비전 기술은 로보틱스 분야에서 중요한 역할을 한다.

## 학습 목표

### 1. 머신러닝과 딥러닝

- 지도학습과 비지도학습의 기본 개념을 이해한다.
- 머신러닝의 주요 알고리즘과 학습 과정을 학습한다.
- 인공신경망과 딥러닝의 기본 구조를 이해한다.
- 학습 데이터와 평가 데이터를 활용하여 모델의 성능을 분석하는 방법을 익힌다.

### 2. 컴퓨터 비전

- 디지털 이미지의 구조와 영상 처리의 기본 개념을 학습한다.
- CNN(합성곱 신경망)의 원리와 활용 방법을 이해한다.
- 이미지 분류와 객체 탐지 기술을 학습한다.
- 객체 분할과 같은 심화된 시각 정보 처리 기술을 알아본다.

### 3. 인공지능 개발 도구

- PyTorch를 활용한 딥러닝 모델 구현 방법을 익힌다.
- 데이터 전처리와 모델 학습 과정을 직접 실습한다.
- 학습 결과를 분석하고 모델의 성능을 개선하는 방법을 탐구한다.
- 강화학습의 기본 개념을 이해하고 로보틱스 분야와의 연관성을 살펴본다.

## 학습 방법

전공 수업과 온라인 학습 자료를 활용하여 머신러닝과 딥러닝의 이론을 익히고, Python과 PyTorch를 활용한 실습을 병행할 계획이다.

먼저 간단한 데이터셋을 활용하여 이미지 분류 모델을 구현하고, 이후 객체 탐지와 같은 컴퓨터 비전 기술로 학습 범위를 넓히고자 한다.

또한 모델의 정확도만 확인하는 것이 아니라 데이터의 특성과 학습 과정에 따른 성능 변화를 분석하며 인공지능 모델이 작동하는 원리를 이해하고자 한다.

## 기대하는 학습 결과

이 단계를 통해 데이터를 기반으로 학습하는 인공지능의 원리를 이해하고, 이미지와 영상으로부터 주변 환경의 정보를 추출하는 컴퓨터 비전 기술의 기초를 갖추고자 한다.

나아가 이러한 지식을 로봇의 환경 인식과 상황 판단에 활용할 수 있도록 준비하고자 한다.
